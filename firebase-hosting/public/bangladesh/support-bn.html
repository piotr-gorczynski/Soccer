হোম টুর্নামেন্ট ও পুরস্কার প্রদান বাংলাদেশের ব্যবহারের শর্তাবলি গোপনীয়তা সহায়তা

সর্বশেষ আপডেট: ৬ অক্টোবর ২০২৬

সহায়তা এবং অ্যাকাউন্ট মুছে ফেলা

সমর্থিত payout wallet হলো bKash এবং Rocket। Payout form-এ first name, last name, wallet provider এবং wallet number দিন। নাম অবশ্যই wallet এবং Remitly recipient details-এর সঙ্গে মিলতে হবে। ভুল তথ্যের কারণে payment বিলম্বিত হতে পারে বা সম্পন্ন নাও হতে পারে।

Gridline Soccer Bangladesh সম্পর্কে সহায়তার জন্য support@piotr-gorczynski.com-এ যোগাযোগ করুন।

Bangladesh সংস্করণটি শুধুমাত্র ১৮ বছর বা তার বেশি বয়সী প্রাপ্তবয়স্কদের জন্য।

পুরস্কার বা payout সংক্রান্ত সমস্যা

অ্যাপে আপনার prize details খুলুন, বর্তমান payment status এবং কোনো issue message থাকলে তা পড়ুন, এবং payout সমস্যা report করার option ব্যবহার করুন। কী ঘটেছে তা সংক্ষেপে বর্ণনা করুন। Support-এর reply আপনি অ্যাপেই পড়তে পারবেন।

যদি payment status-এ Action required দেখায়, তাহলে যখন বলা হবে recipient information সংশোধন করুন। অ্যাপের format check কোনো number গ্রহণ করেছে মানেই সেই wallet বাস্তবে আছে বা transfer গ্রহণ করতে পারবে—এটি নিশ্চিত নয়।

Open অর্থ request জমা হয়েছে। Support replied অর্থ reply পড়ুন এবং প্রয়োজন হলে নির্দেশিত পদক্ষেপ নিন। Resolved বা Closed অর্থ ওই support request শেষ হয়েছে; এটি নিজে থেকে প্রমাণ করে না যে আপনি পুরস্কারের অর্থ পেয়েছেন। সমস্যা থেকে গেলে payout screen থেকে আবার report করুন অথবা support-এর সঙ্গে যোগাযোগ করে আগের reference উল্লেখ করুন।

ইমেইলে যোগাযোগ করলে tournament-এর নাম, support reference থাকলে সেটি, এবং সমস্যার সংক্ষিপ্ত বিবরণ দিন। যে payment-account details payout form-এ দেওয়া যায়, সেগুলোর পূর্ণ তথ্য ইমেইলে পাঠানো এড়িয়ে চলুন। কখনও password, wallet PIN বা one-time code পাঠাবেন না। এই page-এ কোনো নির্দিষ্ট response time-এর প্রতিশ্রুতি দেওয়া হয় না।

অ্যাকাউন্ট বা তথ্য মুছে ফেলার অনুরোধ

অ্যাপে account screen খুলে Remove Account নির্বাচন করুন। যদি অ্যাপে access না থাকে, তাহলে support@piotr-gorczynski.com-এ “Gridline Soccer Bangladesh account deletion” subject দিয়ে ইমেইল করুন। লিখুন যে আপনি আপনার account এবং সংশ্লিষ্ট data মুছে ফেলতে চান। সম্ভব হলে account-এর সঙ্গে যুক্ত email address ব্যবহার করুন। কখনও আপনার password পাঠাবেন না।

আপনার account Global এবং Bangladesh সংস্করণের মধ্যে shared, তাই account removal উভয় সংস্করণে access প্রভাবিত করবে। Bangladesh ব্যবহার করার জন্য Global app uninstall করলে account delete করার প্রয়োজন নেই।

Account removal payout retention period পুনরায় শুরু করে না। Recipient details Completed বা Cancelled status-এর পরে সর্বোচ্চ ১৮০ দিন পর্যন্ত সংরক্ষিত হয়, এবং minimized payment/audit record একই date থেকে পাঁচ calendar year পর্যন্ত সংরক্ষিত হয়। Unresolved dispute বা legal obligation থাকলে retention আরও দীর্ঘ হতে পারে।

বর্তমান in-app removal process সব historical record automatically মুছে দেয় না। Account deletion, payout retention period এবং unresolved dispute বা legal obligation-এর exception সম্পর্কে বিস্তারিত জানতে গোপনীয়তা নীতি পড়ুন।
