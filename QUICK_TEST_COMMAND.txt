================================================================================
QUICK REFERENCE: Running Android Unit Tests Without Real Secrets
================================================================================

COMMAND (Run from mobile/ directory):
  cd mobile && ./gradlew test -Penv=test

OR for a specific variant:
  ./gradlew test_testGlobalDebugUnitTest -Penv=test

================================================================================
WHAT YOU NEED:
================================================================================

The following mock files are required in secrets/ directory:
  ✓ secrets/google-services.test.json   (created - minimal mock)
  ✓ secrets/google-services.dev.json    (created - minimal mock)
  ✓ secrets/soccer_secret_key           (already present)
  ✓ secrets/facebook_client_token       (already present)

The google-services.json files are just valid JSON with required structure.
They don't need real Firebase credentials since tests don't connect to Firebase.

================================================================================
CI/CD WORKFLOWS:
================================================================================

Current workflows in .github/workflows/:
  - npm-audit.yml              (JavaScript/Node.js security)
  - check-translations.yml     (Translation validation)

NO Android test workflow exists. Unit tests can only run locally.

================================================================================
HOW IT WORKS:
================================================================================

1. build.gradle has a copyGoogleServicesJson task that:
   - Copies secrets/google-services.{env}.json → app/google-services.json
   - Fails if the file doesn't exist
   - Plugin processes it (checks JSON structure)
   - Tests don't use actual Firebase, so mock JSON works fine

2. testOptions { unitTests.returnDefaultValues = true }
   - Allows tests to run without full Android runtime
   - Robolectric framework handles this

3. Test dependencies include:
   - JUnit 4.13.2
   - Robolectric 4.16 (Android test framework)
   - Mockito 5.20.0 (mocking)
   - AndroidX Test libraries

================================================================================
FULL COMMAND OPTIONS:
================================================================================

All variants (runs all 6 combinations):
  ./gradlew test -Penv=test

Specific environment:
  ./gradlew test -Penv=dev          # Dev variant
  ./gradlew test -Penv=test         # Test variant
  ./gradlew test -Penv=prod         # Prod variant (if google-services.prod.json exists)

Specific flavor variant:
  ./gradlew test_testGlobalDebugUnitTest -Penv=test       # Test-Global-Debug
  ./gradlew test_devGlobalDebugUnitTest -Penv=dev         # Dev-Global-Debug
  ./gradlew test_testBangladeshDebugUnitTest -Penv=test   # Test-Bangladesh-Debug

Quiet output:
  ./gradlew test -Penv=test --quiet
